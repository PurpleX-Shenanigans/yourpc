# yourpc
made this repo because jiopc sucks
# How to use
1. Get a GitHub account
2. Fork this repo and give it a name
3. In your forked repo, Code > Workspaces > Create codespace on main
4. Wait for devcontainer to build
5. Run [./desktop.sh]
6. wait until the terminal stops, then scroll up to find a cloudflare tunnel
7. visit it and enter "cloudpc" as username and "in-isthebest" as password
# Note
- This is just a throwaway PC, no progress is saved after closing the workspace.
- Your PC may freeze if your workspace stops. Please raise a pull request if you find a way to keep the workspace awake infinitely
